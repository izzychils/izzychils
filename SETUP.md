# Installing this on your GitHub profile

This folder is a drop-in replacement for the contents of your special profile repo:
**`github.com/izzychils/izzychils`** (the repo whose `README.md` renders on your profile page).

## 1. Copy the files

Your profile repo should end up looking like this:

```
izzychils/
├── README.md
├── assets/
│   ├── hero.svg          animated neon banner (name, rotating role, typing line)
│   ├── divider.svg       animated section divider
│   └── previews/         live-demo screenshots used by the project cards
│       ├── chupnow.png
│       ├── oga-plug.png
│       ├── people-growth-africa.png
│       └── onboard.png
└── .github/
    └── workflows/
        └── snake.yml     generates the contribution snake
```

```bash
git clone https://github.com/izzychils/izzychils.git
cd izzychils
# copy README.md, assets/ and .github/ from this folder into the repo
git add README.md assets .github
git commit -m "Redesign profile README with animated hero, project cards and stats"
git push
```

## 2. Turn on the snake

The snake image at the bottom reads from this repo's `output` branch. That branch does not exist
until the workflow runs once, so the image will be blank until then.

1. **Settings, Actions, General, Workflow permissions**: select **Read and write permissions**, save.
2. **Actions, Generate contribution snake, Run workflow** (branch `main`).
3. Wait for the green check, then reload your profile. The `output` branch now holds
   `github-snake.svg` and `github-snake-dark.svg`, and the README picks the right one per theme.

It re-runs every 12 hours after that.

## 3. Things that live outside the repo

These images are generated by public services and need no setup. They only look right if the
username is correct, and every one of them points at `izzychils`:

| Image | Service |
| --- | --- |
| Language grid | `skillicons.dev` |
| Badges | `shields.io` |
| Stats and top languages | `github-readme-stats.vercel.app` (the rank badge is hidden on purpose, public stats do not see client work) |
| Streak | `streak-stats.demolab.com` |

`github-readme-stats` hides private-repo activity unless you deploy your own instance with a
token, so the numbers will look smaller than your real workload. That is expected.

## 4. Editing the animated banner

`assets/hero.svg` is hand-written SVG with SMIL animations (no scripts, because GitHub blocks
those). Everything is in one file:

- **Name**: `#nameText`. The glow colour, gradient and sweep speed are a few lines above and below it.
- **Rotating role**: the three `<text>` blocks under "rotating role". Keep the `keyTimes` in sync
  if you add a fourth role.
- **Typing line**: the `<text>` inside `clip-path="url(#reveal)"` and the matching caret `<rect>`.
  If you change the sentence length, adjust the `630` reveal width and the caret's `695` end position.
- **Chips**: the three rounded rectangles at the bottom (`y="312"`). Widths are hard-coded, so widen
  the `rect` if you write longer labels.

Colours used throughout: `#FF2D87` (neon pink), `#22D3EE` (cyan), `#A78BFA` (violet),
`#0A0E1A` (background).

## 5. About `preview.html`

`preview.html` is a local, GitHub-dark rendering of `README.md` used to check the layout before
pushing. It is not needed on the profile repo, so delete it or leave it out of the commit.
